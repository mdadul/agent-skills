# Code Quality & Refactoring

A collection of skills for writing clean, maintainable code based on Robert C. Martin's Clean Code principles and modern refactoring practices.

## Included Skills

- **clean-code** — Apply Clean Code principles (meaningful names, small functions, error handling, TDD, SRP)
- **code-smells** — Identify and fix code smells and quality issues
- **refactoring** — Refactoring techniques and named patterns
- **pragmatic-programmer** — Pragmatic programmer principles and heuristics
- **dead-code-removal** — Find and safely remove unused code

## When to Use

Trigger these skills when you need to:
- Review code for quality and maintainability
- Refactor toward simpler, clearer structure
- Apply TDD and testing discipline
- Improve naming, error handling, or class design
- Clean up dead code and technical debt
